Methodology — CAHSP = 100 × (0.30·FI + 0.30·QI + 0.20·OI + 0.10·WI + 0.10·CI). Band thresholds: Elite ≥ 90, Solved ≥ 85, High ≥ 70, Moderate ≥ 50, Developing < 50. Dual-mandate gate: FI ≥ 0.50 AND QI ≥ 0.50. See cahsp_score.py for the reference implementation. This baseline uses the direct-from-data proxies in calculate_cahsp_baseline.py: FI from state-level margin + ownership bias, QI from MORT/Safety/READM group-measure counts + star rating, OI as a rating proxy pending per-facility throughput ingestion, WI as a neutral default pending HRSA FTE merge. CI reflects the share of FI/QI/OI signals backed by real data (not fallbacks). The binding-constraint column flags the sub-index with the lowest score for each facility — the first lever to pull.
