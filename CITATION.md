# Citation

If you use the CAH Transformation Engine in academic research, please cite using one of the formats below.

## Preferred Citation

### BibTeX

```bibtex
@software{cah_transformation_engine_2025,
  author       = {Wooden, Aldrich K.},
  title        = {{CAH Transformation Engine: Computational Research 
                   Environment for Critical Access Hospital Innovation}},
  year         = {2025},
  publisher    = {Visionblox LLC / Zuup Innovation Lab},
  version      = {1.0.0},
  url          = {https://github.com/khaaliswooden-max/cah},
  note         = {Mathematical modeling and computational research platform 
                  for CAH operational optimization}
}
```

### APA (7th Edition)

> Wooden, A. K. (2025). *CAH Transformation Engine: Computational Research Environment for Critical Access Hospital Innovation* (Version 1.0.0) [Computer software]. Visionblox LLC / Zuup Innovation Lab. https://github.com/khaaliswooden-max/cah

### IEEE

> A. K. Wooden, "CAH Transformation Engine: Computational Research Environment for Critical Access Hospital Innovation," Visionblox LLC / Zuup Innovation Lab, 2025. [Online]. Available: https://github.com/khaaliswooden-max/cah
