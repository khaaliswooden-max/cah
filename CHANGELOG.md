## Versioning Scheme

### Major Version (X.0.0)
Incremented when:
- Fundamental changes to mathematical framework
- Breaking changes to model interfaces
- Major methodology revisions

### Minor Version (0.X.0)
Incremented when:
- New models or algorithms added
- New research findings published
- Backward-compatible feature additions

### Patch Version (0.0.X)
Incremented when:
- Bug fixes
- Documentation improvements
- Minor corrections to models

---

## Release Process

1. **Feature Freeze** — No new features after freeze date
2. **Testing** — All models validated against MV-CAHI
3. **Documentation** — CHANGELOG updated, docs reviewed
4. **Tag** — Git tag with version number
5. **Release Notes** — Summary for stakeholders
